CitationAI

Cite your AI conversations like any other source.

CitationAI helps scholars build a transparent, permanent record of how they used AI in their research. Paste a conversation and get a ready-to-use citation, linked to a fingerprinted copy of the full exchange, so reviewers, students, and future readers can see exactly what was asked and what came back. It's free, open source, and built so anyone can inspect, self-host, or improve it.

Give it a permanent home

A citation needs a link that will still work in ten years. This first option is free with no real ceiling for text this size — the others below have a genuine cost or cap once you scale up:

  1. Recommended — GitHub + Software Heritage. GitHub doesn't charge for public repo storage and lets you create unlimited public repos, so committing transcripts (a few KB to a few hundred KB each) never really runs into a wall — a single 1 GB repo alone holds thousands of them, and a new repo costs nothing. Commit the file to a public repo, then submit that repo's URL at archive.softwareheritage.org/save. Software Heritage — a nonprofit archive backed by Inria and UNESCO with no user storage quota — mirrors it and issues a permanent, content-based identifier (a SWHID) that keeps resolving even if the repo is later deleted.
  2. Pay-once alternative: ArDrive stores the file on Arweave for a small one-time fee per file — cheap, but it is a real, accumulating cost, not free.
  3. Free-tier alternative: IPFS pinning services like Filebase or 4EVERLAND offer 5 GB free — genuinely free, but genuinely capped.
  4. Optional, extra proof either way: drop the same file into OpenTimestamps (free, no account) to anchor its fingerprint in the Bitcoin blockchain — independent proof it existed, unaltered, as of today.
